# Comments in C++

- Comments are used to explain code & make a easier to understand.
- They are ignored by the compiler & do not affect the program output.
- They increase readability.

# Types of Comments 
## 1. Single Line Comment
```
//This is a single line comment
int i =  7;
```

## 2. Multi-Line Comments
```
/* This is
a multi-line 
comment */
int i = 5;
```

# Real Life Analogy
**Comments are like *Sticky Notes* written in your notebook. 
They help you to understand what is written.**
